# Data Directory

This directory was originally a symlink to `/root/autodl-tmp/UAV-RGBT-Detection/data` on the training server.

The actual dataset (GAIIC2024 Track 1 - Object Detection) is large and not included in this repository. It contains:
- `raw/official/GAIIC2024-赛道1-目标检测任务/` - Official training/validation/test images
- `submissions/` - Representative submission JSON files

To reproduce, download the official dataset and place it under `data/raw/official/`.
