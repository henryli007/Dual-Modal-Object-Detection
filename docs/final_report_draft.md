# 无人机视角下的双光目标检测实验报告

## 1. 任务与数据

本项目面向无人机视角 RGB-T 双光目标检测。输入为成对可见光图像和红外图像，图像尺寸为 `640 x 512`，检测类别包括 `car`、`truck`、`bus`、`freight_car`、`van` 五类。官方数据包含 `17,990` 对训练图像、`1,469` 对验证图像和 `1,000` 对测试图像，训练/验证标注为 COCO 格式，测试集提交单个 COCO detection result JSON。

测试集采集时间和场景与训练集不同，覆盖天气、光照和场景变化。因此本项目以 COCO mAP@[.50:.95] 作为本地筛选指标，同时结合线上反馈判断泛化能力。实验未使用额外外部数据集，仅使用开源预训练模型初始化。

## 2. 方法演进

第一阶段实现了完整的非 YOLO 双流检测框架。数据层面读取 RGB/TIR 成对图像，并保证随机裁剪、翻转、缩放等变换在两种模态和标注框上同步执行。模型层面以 Faster R-CNN 为基础，采用双流 ResNet-50/FPN 特征提取、门控融合和小目标增强策略。推理阶段尝试多尺度、水平翻转 TTA 和 WBF 融合。本阶段验证了 RGB 与红外信息互补的有效性，代表方案本地验证 mAP 约为 `0.5865`。

第二阶段尝试 YOLO 系列检测器。首先构造 3 通道 RGB-T 融合输入，以兼容常规 YOLO 预训练权重；随后进一步构造 `RGB + TIR` 四通道输入，使模型能够显式利用完整可见光和红外信息。4 通道 YOLO 在本地验证集上可达到约 `0.628` mAP，但单独提交线上得分约 `0.31`，说明其对隐藏测试集的泛化能力不足，因此未作为最终主方案。

第三阶段采用更强的双流 GELAN 检测结构。该结构保留 RGB/TIR 双光输入，以更强的骨干网络和检测头提升小目标定位能力。训练过程中修复了当前环境下 NumPy 与 Pillow 的兼容问题，并将 checkpoint 输出迁移到大容量目录，避免训练中断。该阶段多次导出中间 checkpoint 进行线上验证，发现本地验证 mAP 与线上测试分数存在明显分布差异：本地 mAP 提升并不必然带来线上提升。最终选择本地验证 `mAP50-95=0.641` 的 checkpoint 导出提交文件。

此外，还尝试了两类负结果。其一是基于当前最优 checkpoint 进行强增强泛化微调，本地 mAP 提升到 `0.649/0.650`，但线上分数下降，说明该微调方向更偏向本地验证集。其二是对最终预测进行阈值、单图框数和类别分数校准搜索，收益仅约 `0.0001~0.0002`，不足以形成实质提升。因此最终不采用这些候选。

可视化材料见 `docs/figures/`：`method_iteration_gap_cn` 展示三阶段方法迭代，`gelan_training_curve_cn` 展示 GELAN 主训练验证曲线，`gelan_online_probe_cn` 展示中间 checkpoint 的线上探测结果，`final_submission_category_distribution_cn` 展示最终提交预测类别分布。

## 3. 实验结果

| 阶段 | 方法 | 本地验证 mAP@[.50:.95] | 线上反馈/结论 |
| --- | --- | ---: | --- |
| 双流 Faster R-CNN | 门控融合 + TTA + WBF | `0.5865` 左右 | 作为早期可靠基线 |
| YOLO RGB-T | 3 通道/4 通道融合输入 | 最高约 `0.628` | 单独线上约 `0.31`，泛化不足 |
| GELAN 双流检测器 | RGB/TIR 双流强检测器 | `0.641` | 当前最佳主提交 |
| GELAN 泛化微调 | 强增强低学习率微调 | `0.649~0.650` | 线上下降，未采用 |

最终推荐提交文件为：

```text
deliverables/final_submission_gelan_dualstream_e40_under5mb.json
```

该文件大小 `4.697 MB`，包含 `58,410` 个预测框，覆盖 `1000/1000` 张测试图像；审计结果显示无非法类别、无越界框、无非正宽高框，单图最多 `60` 个预测。

GELAN 主训练和泛化微调的原始日志已压缩保存在 `docs/experiment_logs/`，对应的验证指标表保存在 `docs/gelan_main_val_metrics.csv` 和 `docs/gelan_finetune_val_metrics.csv`。

## 4. 分析与结论

实验表明，RGB-T 双光检测的难点不仅在于本地验证集拟合，还在于跨时间、跨光照和跨场景泛化。YOLO 系列在本地指标较高，但线上泛化不稳定；强增强微调虽然继续提高本地 mAP，却未改善线上结果，说明本地验证集与测试集存在明显分布差异。在当前约束下，最有效的提升来自更强的双流检测结构和稳定的检测框召回，而不是继续提高阈值或过度微调。

最终采用 GELAN 双流检测器导出的 e40 结果作为提交候选。该方案在本地验证、线上反馈和提交文件稳定性之间取得了最好的平衡。
